RIVOX DYNAMIC OFFERS — PHASE 1 + 2

Completed:
1. Removed hardcoded YEARLY33 / LAUNCH20 offer cards from the public Pricing page.
2. Public Pricing page now loads current active offers from Supabase.
3. Monthly/yearly plan saving text is calculated from plan prices, not a hardcoded promo.
4. Billing promo validation now uses active database offers.
5. Admin Pricing & Offers now supports:
   - Create
   - Edit
   - Duplicate
   - Delete
   - Enable / disable
   - Schedule start/end dates
   - Search
   - Filter active/scheduled/expired/disabled
   - Featured offer and priority
   - Pro/Business and monthly/yearly targeting
   - Paddle-ready/display-only status
6. Paddle checkout automatically sends a promo code only when the offer is marked Paddle ready.
7. Production build passed.

REQUIRED BEFORE DEPLOYING UI:
Run the new Supabase migration:
  supabase/migrations/20260712120000_dynamic_marketing_offers.sql

Using Supabase CLI:
  supabase db push

Or open Supabase SQL Editor and run the migration file contents.

Then copy this project over your local repository, run:
  npm install
  npm run build
  git add .
  git commit -m "feat(marketing): replace hardcoded offers with admin managed campaigns"
  git push origin main
